# scoop-kktypr

Scoop bucket for KKTypr.

## Installation

Add this bucket to Scoop:

```powershell
scoop bucket add kktypr https://github.com/kk376/scoop-kktypr
scoop install kktypr
```

Or install directly from the manifest URL:

```powershell
scoop install https://raw.githubusercontent.com/kk376/scoop-kktypr/main/bucket/kktypr.json
```

## Update

To update KKTypr to the latest version:

```powershell
scoop update kktypr
```

## Packages
